# Финанс — учёт расходов и бюджета

Веб-приложение для учёта доходов, расходов и бюджетов в духе Spendee: несколько
кошельков, категории, месячные бюджеты по категориям, графики трат. Это
самостоятельный сервер (Next.js + SQLite), а не нативное iOS-приложение — это
специально сделано так, чтобы **данные были доступны сразу со всех
устройств**: телефон, планшет, компьютер — просто открываете один и тот же
адрес в браузере и видите одни и те же операции. На iPhone сайт можно
установить на домашний экран как обычное приложение (PWA).

## Стек

- Next.js 16 (App Router) + TypeScript + Tailwind CSS
- Prisma 7 + SQLite (через `better-sqlite3`) — простая файловая база, которую
  легко бэкапить и переносить
- Аутентификация: email + пароль, сессия в httpOnly-куке (JWT, `jose`)
- Recharts — графики расходов по категориям

## Быстрый старт (локальная разработка)

```bash
npm install
cp .env.example .env        # укажите свой JWT_SECRET, см. ниже
npx prisma migrate deploy   # создаёт файл базы данных и применяет схему
npm run dev
```

Откройте http://localhost:3000, зарегистрируйтесь — автоматически создастся
кошелёк по умолчанию и набор категорий расходов/доходов.

Сгенерируйте свой секрет для подписи сессий:

```bash
openssl rand -hex 32
```

и впишите его в `.env` как `JWT_SECRET`.

## Развёртывание, чтобы пользоваться с нескольких устройств по сети

Приложению нужен один постоянно работающий сервер с общей базой данных —
тогда телефон, планшет и ноутбук будут видеть одни и те же операции сразу
после входа в аккаунт. Проще всего поднять его в Docker на своём
сервере/NAS/VPS или даже на домашнем компьютере, который доступен по сети.

### Вариант 1: Docker Compose (рекомендуется)

```bash
echo "JWT_SECRET=$(openssl rand -hex 32)" > .env
docker compose up -d --build
```

Приложение поднимется на порту `3000`, база данных SQLite хранится в
именованном Docker-томе `app-data` — переживает пересоздание контейнера и
обновления образа. Дальше:

- Если сервер доступен только в домашней сети — заходите с телефона/ноутбука
  по адресу `http://<IP-компьютера>:3000`.
- Если хотите доступ из интернета (например, чтобы работало вне дома) —
  поставьте перед приложением обратный прокси с HTTPS (Caddy, Nginx +
  Let's Encrypt, Cloudflare Tunnel) и опубликуйте порт 3000 через него. HTTPS
  обязателен: без него iOS не даст нормально установить сайт на домашний экран
  и куки сессии будут менее защищены.

### Вариант 2: обычный Node-сервер (VPS)

```bash
npm ci
cp .env.example .env   # задайте JWT_SECRET и DATABASE_URL, например file:./data/app.db
npx prisma migrate deploy
npm run build
npm start -- -p 3000
```

Запустите процесс через `pm2`/`systemd`, чтобы он поднимался автоматически
после перезагрузки, и настройте reverse proxy с HTTPS, как в варианте выше.

### Резервное копирование

База данных — один файл SQLite (путь задаётся `DATABASE_URL`, при
Docker-развёртывании — `app-data` том, файл `app.db` внутри). Чтобы сделать
бэкап, достаточно скопировать этот файл, пока приложение остановлено, либо
использовать `sqlite3 app.db ".backup backup.db"` на лету.

## Установка на iPhone как приложение (PWA)

1. Откройте адрес сервера в Safari.
2. Нажмите «Поделиться» → «На экран «Домой»».
3. Готово — иконка появится на рабочем столе и будет открываться в полноэкранном режиме, как обычное приложение.

Работает точно так же на Android (Chrome → «Добавить на главный экран») и как
обычная вкладка в браузере на компьютере.

## Основные возможности

- Несколько кошельков (карты, наличные, счета) с разными валютами
- Расходы, доходы и переводы между кошельками
- Категории с иконками и цветами, свои и предустановленные
- Месячные бюджеты по категориям с индикатором прогресса
- Обзорный экран: общий баланс, доходы/расходы за месяц, разбивка по
  категориям на диаграмме, последние операции
- Один аккаунт — общие данные на всех устройствах, где выполнен вход

## Структура проекта

```
app/(auth)/        страницы входа и регистрации
app/(app)/          основной интерфейс (обзор, операции, бюджеты, кошельки, ещё)
app/api/             REST API (аутентификация, кошельки, категории, операции, бюджеты)
components/          переиспользуемые UI-компоненты и модальные окна
lib/                  доступ к БД, аутентификация, форматирование, общие типы
prisma/schema.prisma  схема базы данных
```

```bash
npm run dev            # разработка
npm run build           # production-сборка
npm start                # запуск собранного приложения

npx prisma migrate dev  # создать новую миграцию после изменения schema.prisma
```
